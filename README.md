# Piano Flow

Akan notalara dokunarak piyano çalınan bir ritim oyunu (Flutter).

## Durum

Proje iskeleti kuruldu. Oyun mekaniği henüz yok — adım adım ekleniyor.

## Geliştirme

Flutter 3.35+ gerekir.

```bash
flutter pub get
flutter run          # cihaz veya emülatörde çalıştır
flutter test         # testler
flutter analyze      # statik analiz
```

## Klasörler

```
lib/
  app.dart            uygulama kökü
  main.dart           giriş noktası
  screens/            ekranlar
  theme/              renk ve tipografi
test/                 testler
```
