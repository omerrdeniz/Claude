# Claude çalışma deposu

Bu depo birden fazla projeyi barındırır; her proje kendi klasöründe durur
ve kendi `CLAUDE.md` dosyasını taşır. Kökteki `CLAUDE.md` ise bütün
projelerde geçerli genel çalışma kurallarıdır.

| Klasör        | Proje                                              |
| ------------- | -------------------------------------------------- |
| `piano-flow/` | Piano Flow: akan notalara dokunarak çalınan ritim oyunu (Flutter) |

Yeni bir proje açarken kökte yeni bir klasör oluşturun ve projeye özgü
kuralları o klasörün içindeki `CLAUDE.md` dosyasına yazın.
